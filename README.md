A simple, interactive command-line game built as my first minor project. The goal is to challenge the user's logic and luck by guessing a hidden number within a limited number of attempts.<b>
🚀 How it Works<b>
The computer selects a random integer between 1 and 100. Your mission is to find that number in 7 attempts or less.

For every guess you make, the computer provides feedback to guide you:

"Too Low": Your guess is less than the target number.

"Too High": Your guess is greater than the target number.

"Congratulations!": You've cracked the code!<b>

🛠️ Features<b>
Randomized Gameplay: A new number is generated every time you play.

Win/Loss Logic: Specific conditions to check if the user has run out of attempts.

Interactive Feedback: Real-time hints based on user input.

Input Validation: (Optional: Mention this if your code handles non-numeric inputs or numbers out of range).<b>


📋 Game Rules<b>
The range is strictly between 1 and 100.

You have a maximum of 7 tries.

If you fail to guess the number within the limit, the game ends and reveals the secret number.<b>

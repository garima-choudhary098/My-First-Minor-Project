A simple, interactive command-line game built as my first minor project. The goal is to challenge the user's logic and luck by guessing a hidden number within a limited number of attempts.<br>
🚀 How it Works<br>
1.The computer selects a random integer between 1 and 100. Your mission is to find that number in 7 attempts or less.

2.For every guess you make, the computer provides feedback to guide you:

3."Too Low": Your guess is less than the target number.

4."Too High": Your guess is greater than the target number.

5."Congratulations!": You've cracked the code!<br>

🛠️ Features<br>
1.Randomized Gameplay: A new number is generated every time you play.

2.Win/Loss Logic: Specific conditions to check if the user has run out of attempts.

3.Interactive Feedback: Real-time hints based on user input.

4.Input Validation: (Optional: Mention this if your code handles non-numeric inputs or numbers out of range).<br>


📋 Game Rules<br>
1.The range is strictly between 1 and 100.

2.You have a maximum of 7 tries.

3.If you fail to guess the number within the limit, the game ends and reveals the secret number.<br>
